🛒 AI Smart Retail — Demand Forecasting & Inventory Analytics Platform

AI-powered retail analytics platform built to simulate modern retail and supply chain workflows through demand forecasting, inventory monitoring, and operational analytics.

The platform combines machine learning, scalable backend services, and interactive dashboards to help analyze product demand patterns and inventory trends in a retail environment.

📌 Features

- Demand forecasting using machine learning models
- Inventory monitoring and product demand analysis
- Interactive dashboard with charts and KPI tracking
- Real-time frontend and backend integration
- REST API architecture using FastAPI
- Database-driven analytics workflows

🛠️ Tech Stack

**Backend**
- FastAPI
- Python
- SQLite
- SQLAlchemy
- Pydantic

**Frontend**
- React
- Vite
- Tailwind CSS
- Recharts
- Framer Motion

**Other**
- Machine Learning
- REST APIs

🏗️ System Architecture

React Dashboard
      ↓
FastAPI REST APIs
      ↓
Analytics & ML Layer
      ↓
SQLite Database


📊 What the Project Does

- Forecasts product demand trends
- Tracks inventory-related insights
- Visualizes operational KPIs through dashboards
- Processes retail data for analytics workflows
- Demonstrates scalable backend integration patterns

🚀 Why This Project Matters

This project was designed to reflect engineering concepts commonly used in modern retail and supply chain platforms, including:

- analytics-driven decision systems
- backend service architecture
- retail data processing workflows
- inventory optimization concepts
- scalable API-based application design

⚙️ Local Setup

### Backend

cd backend

pip install -r requirements.txt

python seed_data.py

uvicorn main:app --reload
Backend runs on:

http://127.0.0.1:8000

### Frontend

cd frontend

npm install

npm run dev

Frontend runs on:

http://localhost:5173
